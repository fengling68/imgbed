## imgbed 全量转 WebP（本地工具）
- 写了 `convert_to_webp.py`（Pillow，venv 在 `~/.workbuddy/binaries/python/envs/default`，已装 Pillow 12.3.0）。
- 结果：336 张图 → 334 WebP + 1 SVG(跳过) + 1 已高度优化 JPEG(转 WebP 反而更大，保留原格式)。
- 体积 327.3 MB → 129.1 MB（约省 60.6%）。脚本默认开启「绝不增大」策略：WebP 比原图大时降到更低质量重试，仍大则保留原格式。
- 关键坑（已修复）：源本身就是 `.webp` 时 `webp_path == path`，旧代码在 `os.replace` 后又 `os.remove(path)` 会把刚写好的文件删掉。修复：`if webp_path != path: os.remove(path)`。
- 经验：原地替换前先确认文件是否被 git 跟踪（imgbed 是 git 仓库，未跟踪文件无法恢复）。本任务中一度误删了 5 个未跟踪的 webp 及一批原图，全部用 `git checkout -- <path>` 从 HEAD 恢复后重新转换，最终 0 丢失。
- 注意：imgbed 是图床，转成 webp 后所有外部引用（.jpg/.png 链接）需同步改成 .webp。
- 报告明细在 `webp_convert_report.json`；改动均未提交（用户自行决定是否 commit）。
